# 页间 · EPUB 阅读器

本地 EPUB 阅读器。支持导入电子书、目录跳转、翻页、调整字号、夜间模式、划线和笔记，并把笔记写入 Obsidian 仓库的 `EPUB 阅读笔记` 文件夹。

## 运行

需要 Node.js 20.19+ 和 npm。

```powershell
npm install
npm start
```

安装依赖后，在 Windows 上也可双击 `启动阅读器.cmd`。本仓库包含源码；本地生成的 `release/` 便携版不纳入 Git 版本管理。

首次运行时点击“导入 EPUB”，然后点击左下角“选择仓库文件夹”，选择 Obsidian 仓库的根目录。之后每次保存或删除笔记都会自动更新对应的 Markdown 文件。也可以在笔记栏右上角点击同步按钮。

阅读进度和图书副本保存在 Electron 的用户数据目录。笔记文件使用固定的管理标记；标记以外的文字会保留。请勿手工改动标记内的自动生成内容，否则下次同步会覆盖该部分。仓库同步是本地文件写入；跨设备同步由 Obsidian Sync、网盘或你自己的同步工具负责。

目前仅支持无 DRM 的 EPUB 文件。笔记从阅读器向 Obsidian 单向同步。

Markdown 笔记按书中章节归类，同一章节标题只显示一次；每条摘录后显示自己的笔记，不展示记录时间或 CFI。阅读器仍保存原文位置，可通过“编辑 / 定位”返回对应段落。新生成文件只自动更新摘录与笔记区块，区块外的书籍说明和标签可以自行编辑。
