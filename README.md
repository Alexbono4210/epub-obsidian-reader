# 页间 V0.2 · 阅读、启发与行动

本地 EPUB 阅读器。阅读时记录摘录和自己的想法；结束本次阅读后，进入独立的读后回顾页面，先写下启发，再用自己配置的 API 与 AI 讨论，选一个小行动，执行后回来记录结果。

## 双击启动

双击本文件夹里的 `打开阅读器.cmd`，或 `release/页间/页间 V0.2.exe`。便携版无需安装 Node.js。整个 `release/页间` 文件夹需要保留在一起。

## 使用流程

1. 导入 EPUB，正常翻页、选中原文记录摘录，也可以点击“随手记”直接输出想法。阅读页面没有 AI 功能。
2. 点击“结束本次阅读”。读到这里有一点启发就可以结束，不以 100% 进度为门槛。没有启发也可以直接返回书架。
3. 写下自己的启发，勾选与本次讨论有关的摘录和笔记，点击“保存启发，进入对话”。此时仅保存到本机，不调用 API。
4. 在回顾页面的“API 设置”中填写接口地址、模型名称和 API Key。支持 OpenAI 兼容的 Chat Completions 接口，可输入基础地址（如 `https://服务地址/v1`）或完整的 `/chat/completions` 地址。模型 ID 以服务商为准。远程服务使用 HTTPS；本地服务支持 localhost HTTP。
5. “保存并测试”发送一句简短问候，可能产生少量费用。保存后点击“请陪我讨论这点启发”或输入问题，开始多轮对话。支持停止等待、失败重试、关闭后继续历史回顾；Ctrl+Enter 可以发送。
6. 有价值的 AI 回复点击“保留这条回复到回顾”。在右侧填写一个行动：做什么、何时/什么情境、如何观察。执行后编辑行动，填入结果并勾选已执行。
7. 保留回复或保存行动时自动同步回顾。也可以点击“保存回顾到 Obsidian”导出并打开文件。完整对话保存在本机，仅选中的 AI 回复导出。

## 数据与旧版

- V0.1 源码与便携版保留在上一级文件夹。
- V0.2 数据独立保存在 `%APPDATA%/epub-obsidian-reader-v02`，第一次启动复制 V0.1 的书籍、笔记、阅读位置和 Obsidian 设置。以后两个版本的数据各自保存。
- V0.2 摘录与回顾写入 Obsidian 的 `EPUB 阅读笔记/V0.2`；第一次迁移也复制已有导出文件，保留手动编辑的说明。旧版导出文件继续保留。
- 摘录按章节分组，不逐条展示时间和 CFI；阅读器仍保存定位。同步只替换管理标记内的内容，标记外的手写内容保留。笔记及回顾从应用向 Obsidian 单向同步；手改管理区块会在下次同步时覆盖。
- 不支持带 DRM 的 EPUB。跨设备同步由 Obsidian 或用户的同步工具完成。

## AI 使用范围

- API Key 使用 Electron safeStorage / Windows 系统加密保存在本机配置文件中，不返回给阅读页面，也不写入 Obsidian。更换电脑或 Windows 账户后可能需要重新输入。
- 点击发送才会把书名、自己的启发、勾选的笔记快照、本次行动与结果，以及本次对话发送给配置的服务商。不会扫描 Obsidian 其他文件，也不会上传整本 EPUB。
- AI 仅知道提供的材料，不掌握整本书；提示中要求区分原文、用户想法和推断。回答仍需自行判断。
- 每次回顾材料上限约 5 万字符，对话总上下文上限约 8 万字符，实际支持长度还取决于服务商模型。超长时减少材料或新建回顾。请求最长等待两分钟，支持取消。
- 支持文本、非流式 Chat Completions。仅支持 Responses、Claude 原生等其他协议的服务，需使用兼容网关。

## 对话方式

AI 默认先理解并检验你的想法，给出有依据的判断或不同意见，并承接前面已经说过的内容。回复长度跟随问题，不再使用统一的 300 字限制，也不要求每轮都提问或制定行动。引用材料时可使用“笔记 1 + 章节”定位，材料预览中显示对应编号。

只有当你想实践时，才进一步讨论小行动；回看结果时区分实际观察与可能的解释。没有整本书的材料时，AI 不应假装掌握整本书。实际回复效果取决于所配置的模型，需要用真实对话验证。可用 [对话质量验收](docs/对话质量验收.md) 中的虚构场景比较表现。

## 源码开发

需要 Node.js 20.19+。

```powershell
npm install
npm start
npm test
npm run test:runtime
npm run package
```

运行时测试使用临时数据、合成 EPUB 和本机模拟 API，不读取个人书籍，不调用收费服务。打包输出到 `release/页间`，源码中的 `release/` 不纳入 Git。

实现参考：[Chat Completions 接口文档](https://developers.openai.com/api/reference/resources/chat)、[Electron safeStorage 文档](https://www.electronjs.org/docs/latest/api/safe-storage)。
